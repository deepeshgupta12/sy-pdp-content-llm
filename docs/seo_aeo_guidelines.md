# SEO + AEO Rules (Operational)

- Lead every section group with a 40–60 word direct answer summary (AEO “answer box”).
- Obey E-E-A-T: cite reputable sources for claims; avoid speculation.
- No duplication: do not restate raw PDP fields verbatim; summarize and add new context.
- Structure for extraction: H2/H3 by questions; include FAQ; generate schema (FAQPage/HowTo).
- Use conversational, precise language; avoid fluff.
- Multimedia: propose tables/images/video ideas; we’ll handle assets downstream.
